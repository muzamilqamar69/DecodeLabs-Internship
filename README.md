# Responsive Frontend Interface

A modern, mobile-first React landing page built with clean architecture, responsive design, and lightweight animations.

## Project Overview

This project demonstrates a professional startup landing page with a responsive navigation system, hero section, features grid, information section, statistics counters, call-to-action block, and footer.

## Features

- Responsive Navbar with animated mobile menu
- Mobile-first hero layout with dual CTAs
- Feature cards using CSS Grid
- Information section with bullet points and illustration
- Statistics cards with animated counters
- Footer with quick links and social items
- Clean, accessible HTML structure and keyboard-friendly interactions

## Installation

1. Install dependencies

```bash
npm install
```

## Running the app

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Responsive Strategy

Built mobile-first and scaled with responsive breakpoints for 375px, 425px, 768px, 1024px, and 1440px. Uses CSS Grid and Flexbox for layouts and transforms for smooth states.
